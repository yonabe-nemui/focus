# プロジェクト概要
- **アプリ名:** Focus
- **目的:** RSS/情報集約アプリ
- **コアバリュー:** 「見たくないものは見ない」。ユーザーが情報を完全に制御し、不快な情報や不要な情報を徹底的に排除できる環境を提供すること。
- **技術スタック:** Kotlin Multiplatform (KMP), Compose Multiplatform
- **プロジェクトID:** app.focus.personal

# 振る舞い
- 常にこのプロジェクトのコンテキストを考慮して回答してください。
- ユーザーとのやり取りはすべて日本語で行ってください。
- 文字列などはハードコーディングせず、リソースファイル（strings.xml 等）を適切に使用してください。
- 専門的な実装については、適宜 `kmp-expert` スキルを参照してください。
- BlueSkyの実装においては、ログイン機能とユーザー設定（ミュートワード等）の同期を最優先とし、パーソナライズされたクリーンなフィードを実現します。
